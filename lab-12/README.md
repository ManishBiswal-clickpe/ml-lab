# Lab 12: Naive Bayes classifier

Based on Lab12_NavieBayesClassifier.txt in the [Classroom assignment](https://classroom.google.com/c/ODcxMzk3MDI5NDkz/a/ODkyMTY1MzQxMzY5/details?email=b523035@iiit-bh.ac.in&pli=1), posted October 14, 2026.

Runs GaussianNB on scikit-learn's Iris dataset with a stratified 80/20 split and random_state=42. Prints accuracy, macro precision and recall, the confusion matrix and the classification report. The supplied starter requests no graph.

Run `python lab.py` after installing the repository requirements. Verified accuracy: 96.67%; macro precision: 0.9697; macro recall: 0.9667. Actual output is included at the bottom of lab.py. The starter's explanatory comments were removed; the algorithm is unchanged.
