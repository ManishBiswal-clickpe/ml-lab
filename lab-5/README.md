# Lab 5: Neural network classifier

MLP classifier on Iris with three hidden layers of 10 neurons, a 75/25 train-test split, predictions, confusion matrix, and overall accuracy. Preserves the starter's first three feature columns and unscaled inputs.

Reads the Classroom CSV with `header=None` so all 150 rows are kept. Uses `random_state=42` for the split and MLP to make runs repeatable. The starter's comment says 80/20, but its code uses 75/25; this keeps the code's split. Converted the posted starter notebook to a script; no notebook submission was specified. This lab produces no graphs.

Run `python lab.py` from this folder after installing the repo's `requirements.txt`. Printed output from a real run is in comments at the bottom of the script.

Dataset: [Classroom IRIS.csv](https://drive.google.com/file/d/1-q6NZPYHD1nqveQ9hfKu2OzxfiJV9SWU/view?usp=classroom_web&authuser=0).
