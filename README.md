# Machine learning labs

Python programs, printed outputs, and graphs for the labs posted in Classroom.

Included: labs 1, 2, 3, 6, 7 and 8. Labs 5 and 11 are deferred. Syllabus-only experiments are not included.

## Run

Use Python 3.10 or newer. Install `requirements.txt`, then run `python lab.py` from the lab folder. Lab 1 also includes `basic_exercises.py`.

## Results

All seven Python programs ran successfully. PNGs are in `figures/` and `script-figures/`; printed results are in the output text files. `script-execution-report.json` records successful script runs.

## Data and implementation notes

The posted starters were adapted for execution. Adaptation notes are in each lab README. Iris has 150 headerless rows, Liss-III has 400 rows, and Salary_Data has 30 rows. Lab 1's students.csv is explicitly generated example data for the basic CSV exercises, not a downloaded class dataset.
